# 《女神異聞錄：夜幕魅影》官方網站(260409)

《女神異聞錄：夜幕魅影》(P5X) 官方網站首頁。本次更新（5.0.1 版本）將角色服裝型態切換機制擴充為支援「四型態」，並套用在「新井素羽」卡片新增第 4 套服裝型態，同步更新首頁主視覺 KV 圖、Slogan、遊戲特色輪播首圖與自動彈窗廣告。

- 正式網址：https://www.p5x.com.tw/

## 遊戲背景

《女神異聞錄：夜幕魅影》是由 SEGA 正版授權、ATLUS 深度參與，完美世界遊戲打造的《女神異聞錄5》首款手遊。本作基於 P5 的世界觀設定展開故事，在深度還原原作潮酷炫風格的基礎上，由全新角色和全新劇情帶來全新的精彩體驗。

## 頁面內容

- **Nav 導航**：社群連結（Facebook／YouTube／Discord／Groups／Twitter／Telegram）、背景音樂開關，手機版另收合為漢堡選單並附儲值購點／購點教學／常見 FAQ 捷徑。
- **Header（刊頭）**：主視覺背景影片、Slogan、預告影片彈窗（Lity）、各平台下載按鈕（App Store／Google Play／Google PC／Windows）與事前登入按鈕。
- **遊戲新聞（`news`）**：輪播廣告 Banner＋最新／新聞／活動／系統四個分類的消息列表。
- **角色介紹（`character`）**：5 個分頁頁籤（主角團、怪盜偶像、心之怪盜團、S.E.E.S.、P5R 聯動限定角色），各分頁以 Swiper 輪播呈現角色立繪（部分角色提供 2～4 種型態切換）、角色資訊卡（姓名、CV、代號、人格面具、簡介文字）與角色專屬語音試聽按鈕。
- **校園生活（`school`）**：3 張輪播介紹校園日常、都市探索、人際協作等玩法，可點擊縮圖放大查看完整場景圖。
- **異世界之旅（`metaverse`）**：4 張輪播介紹異世界探索、天鵝絨房間、印象空間、改心行動等核心玩法。
- **遊戲特色（`feature`）**：輪播宣傳圖，展示 City Walk、異世界探索等遊戲特色畫面。

## 本次更新內容（5.0.1 版本）

- **角色型態切換機制擴充為「四型態」**：原本的切換按鈕（`.role_change_type`）只能在型態 1／2／3 之間循環，本次新增 `.role_change_4` 按鈕與 `type_c` 狀態，改為在四種型態間循環（型態4→1→2→3→回型態4），並將人格面具背景顯示邏輯重構為共用函式 `handleBgPersona()`，新增 `bg-hide-on-form4` class 供特殊角色設定「僅型態4顯示時才隱藏背景立繪」。
- 「新井素羽」套用四型態機制，新增第 4 套服裝立繪（`role1_3_4.webp`），卡片預設顯示型態4，並標記 `bg-hide-on-form4`（背景立繪僅型態4時隱藏，其餘型態照常顯示）。
- 專案內附「第4型態 更新操作」資料夾，整理了未來新增四型態角色的操作手冊：複製既有分頁 HTML 結構、CSS 設定新角色立繪位置與按鈕圖示、JS 僅需在 `character_main.js` 既有的 slide 清單中加入新的分頁 ID，不需再新增邏輯。
- 首頁主視覺 KV 影片背景圖與 Slogan 圖更新（`kv_vdeo_bg_pc_260409.webp`／`kv_vdeo_bg_tb_260409.webp`／`slogan_260409.webp`）。
- 遊戲特色輪播首張宣傳圖更新為 `slide1_260409.png`，其餘宣傳圖沿用先前版本素材。
- 自動彈窗廣告圖更新為 `pop_img_260409.webp`（手機版 `pop_img_260409_sp.webp`）。
- CSS 版號同步更新為 `main_260409.css`／`mobile_260409.css`／`main_character_all_260409.css`；主要頁面腳本（`main_20260409.js`）本次內容與前一版相同，僅檔名版號更新。

## 版面規格 / RWD

- 桌機版面（`main_260409.css`）以 `%`／`vw` 等彈性單位定位 KV 裝飾元素、角色立繪等視覺細節，讓整體版面隨視窗寬度等比縮放。
- 手機／平板版面另外獨立拆分成 `mobile_260409.css`：先在 1200px／1195px／767px 幾個斷點做少量平板過渡調整，主要的手機版覆寫規則則集中在 750px 以下，重新定義間距、字級與版面排列。
- 角色介紹區塊的樣式獨立拆分為 `main_character_all_260409.css` 另一支檔案做版本化管理，新增角色時只需在這支檔案追加對應的樣式區塊，不需異動主版面 CSS。
- 多數圖片與角色立繪皆額外提供 `.mob` 手機版圖源，依斷點切換顯示對應桌機／手機版本的視覺素材。
